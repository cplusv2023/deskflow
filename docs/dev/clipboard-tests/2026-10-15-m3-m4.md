# Ubuntu 剪贴板 M3/M4 组件增量验证

日期：2026-10-15，Asia/Shanghai。基线提交 `0f08f3111573eb0d0f01e0189baa8c104bd3ffcc`，本轮使用其后的工作区代码。

本轮向 M5 推进前置基础：四格式 X11 接入、真实文件按需提供、租约、Broker 状态和独立进程文件投影。**尚未接入 deskflow-core，M3/M4 的完整持续运行时与 M5 均未宣告完成。** 没有 Mac 实机，也没有正式文件 TLS 连接。

## 环境与重跑

Ubuntu 26.04.1、GNOME Wayland、GCC 15.2、CMake 4.2.3、libfuse3 3.18.2、libX11 1.8.13、libXfixes 6.0.0。未安装系统软件；Xvfb 21.1.22 从系统软件源下载后提取到独立临时目录，使用私有显示连接。测试没有访问当前桌面剪贴板。

```bash
cmake -S src/apps/clipboard-prototype -B build/clipboard-prototype \
  -G Ninja -DCMAKE_BUILD_TYPE=Debug -DCLIPBOARD_PROTOTYPE_FUSE_TESTS=ON
cmake --build build/clipboard-prototype --parallel 4
# Xvfb 在 PATH 时可直接运行；否则指定本机的绝对可执行路径：
XVFB_BINARY=/absolute/path/to/Xvfb \
  ctest --test-dir build/clipboard-prototype --output-on-failure
```

未启用 `CLIPBOARD_PROTOTYPE_DESKTOP_TESTS`，因为旧 X11 桌面测试会暂时持有用户剪贴板。FUSE-only 开关只在专用临时目录挂载。

最终独立构建通过，**8/8 个 CTest 目标通过，0 跳过，耗时 7.45 秒**。主工程显式使用系统 Qt 6.10.2 配置后，三个可选原型目标也全部编译成功。本轮没有重建主程序或重新执行原有 31 个单元测试，不计作 M5 回归完成。

21 个相关 C++ 源码／头文件通过仓库指定的 clang-format 20.1.0；三个纯 C++ 测试程序分别通过 `-Werror` 与 ASan/UBSan 检查，合计七组源服务、十二组 Broker 和四组 typed-client 用例。Markdown 本地链接、Python 语法及 fixture JSON 检查通过。

X11 的 PNG 样本是有效的 787252 字节图片，双向 INCR 后字节一致。文本、HTML、URI 列表保留原始字节；覆盖外部 INCR、TARGETS/TIMESTAMP/MULTIPLE、所有权变化、同窗口重新取得所有权、超限、提供器失败及原子输出。采集 GNOME `cut` 不降级为复制；非法 URI、远程主机、NUL 与路径歧义被拒绝。监听只取公告与目标列表，不读文件主体。

真实文件数据不整体读入源端内存。目录清单固定且有界，普通文件 `immutable` 打开返回 `SOURCE_NOT_STABLE`；测试显式选择 `detectable`。该模式检查身份、权限、大小及变化时间，检测变更后立即失败，**不保证任意并发写入下的不可变快照**。

FUSE 测试的 4 GiB + 123 字节文件为稀疏文件，只在指定偏移写少量测试数据。完整复制的是 1 MiB + 37 字节样本并校验 SHA-256，不能将它记作 4 GiB 整文件复制通过。最终接收进程 VmHWM/VmRSS 为 6196 KiB；该值属于本机测试，不推断网络性能。

## 生命周期与错误

- whole-offer 租约保留未打开的后代；源与 Broker 测试均覆盖 A 被 B 替换后的后续访问。固定单公告 FUSE 挂载的 TTL=600 ms，空闲 1.35 秒后仍能打开子项，证明不依赖活跃句柄续租。
- FUSE 多线程调用串行接入一条实验连接，单次源请求至多 256 KiB；最大帧 1 MiB。实验服务单连接工作，不等同于生产多端并发实现。
- 读取消费显式 status/bytes/eof，正数短响应继续聚合；非 EOF 零响应和对象／版本／请求不匹配失败。取消／超时后关闭流，残帧与迟到字节不会交付给下一次请求。
- 输出由 CLI 消费者在用户目标目录中以临时名称写入，成功后将同一 inode 原子链接为目标名称；失败删除，已有目标不覆盖。源服务和 FUSE 提供器不创建完整正文缓存。
- 干净卸载关闭句柄并释放租约；关闭、续租和读取等待必须受退出清理期限约束。测试使用独立进程和私有目录，结束后无测试挂载与套接字。
- 将单次 RPC 超时设为 600000 ms，代理分别无限阻塞 open/renew/close/release 响应，退出耗时为 265.3/513.1/265.2/504.5 ms。正常续租在宽限内完成时，仍记录 `lease_released=CLOSED` 和 `rpc_shutdown=OK`；不是依靠每次强制断线伪造释放成功。

## 尚未验收

- GNOME 原生 Wayland 应用的文本／HTML／PNG／文件四格式采集和发布；隔离 Xvfb 不替代这些用例。
- Broker 动作与长期后端、自动源公告、多个挂载公告的统一运行时。当前 Broker 只管理文件公告，文本／HTML／PNG 尚未接入同一状态机；`serve --from-clipboard` 只采集一次，之后不会自动同步新剪贴板。
- 真正在持续原生目录复制中换成 B，再由同一运行时打开 A 的未访问子项。当前是源、Broker 和单公告挂载分别验证。
- Files 用户取消、实际 core 停止／重连／挂起、Portal/X11 所有权冲突、legacy 适配和焦点独立的多端广播。
- 正式能力协商、独立 TLS、主会话身份／凭据绑定、真实键鼠响应预算与 Mac 实机。
- 由共享 `faultPlans` 直接驱动的两端统一 runner，以及全部日志格式迁移。
