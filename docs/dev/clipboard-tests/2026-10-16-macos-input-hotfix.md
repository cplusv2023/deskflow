# macOS v1 输入与设置修复

基线：`aabb62d0d`（`clipboard-v1`）。用户反馈每次打字出现
`can't get the active group`，同时感觉客户端鼠标卡顿。

## 代码发现与修改

- `kTISPropertyInputSourceID` 是 CFString，原实现将它当作 CFData 指针作为 map 键。
  指针身份不能保证输入源内容相等。改用拥有生命周期的 UTF-8 字符串作为键。
- 活动组查询与现有按键翻译使用同一布局选择逻辑，包含输入法下的 ASCII 布局回退。
  持续找不到布局只告警一次，成功匹配后恢复告警能力；不再逐键刷屏。
- 刷屏增加日志及 GUI 处理开销，错误布局也可能触发布局切换路径的等待。
  这些是卡顿的可能贡献因素；没有测量端到端输入延迟，不能据此断言鼠标卡顿全部解决。
  本次不调整网络参数或鼠标事件合并策略。
- 新剪贴板启用时隐藏服务器配置中的旧开关、旧大小限制，提示到“设置”管理。
  保存时保持 core 协商前提有效，并在必要时重置 Wayland Portal token。
  未启用新服务的旧兼容模式仍可使用旧设置；不改写用户外部服务器配置文件。
- 客户端原有 X/Y 滚轮反转设置及 macOS 注入链路已存在。本次明确命名“鼠标滚轮 / 反转方向”，
  补充中文和说明，复用原有持久设置、倍率和保存后重连行为，不新增重复参数。

## 验证与交付

按用户要求不运行功能验收测试、输入注入或跨端复制测试。
仅执行 Release 编译、静态差异检查、App 依赖检查及签名验证。
新产物：`dist/macos-clipboard-v1.0.1/Deskflow.app` 与
`dist/Deskflow-clipboard-v1.0.1-macos27-arm64.zip`。
运行条件仍为 Apple Silicon、macOS 27+、macFUSE 5.4.0 FSKit；ad-hoc 签名、未公证。
包含 `clipboard-v1` 的所有文件 URL 与 reader 生命周期修复。
退出旧 App 后启动新产物并重连，旧进程不会自动获得这些修复。
